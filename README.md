# 🩺 MediAgenda — Tu salud, con hora y fecha

**MediAgenda** es una aplicación web intuitiva y moderna diseñada para simplificar la gestión de citas médicas. Permite a los usuarios agendar, consultar, reprogramar y cancelar citas sin necesidad de llamadas telefónicas ni largas esperas.

🌐 **Demo en vivo:** [MediAgenda Web](https://melinaortiz018-code.github.io/mediagendaweb/)

---

## ✨ Características Principales

- **Dashboard / Inicio:**
  - Resumen visual con métricas en tiempo real (próxima cita, total de citas agendadas, citas completadas y médicos disponibles).
- **Agendamiento Inteligente de Citas:**
  - Proceso paso a paso guiado:
    1. Selección de especialidad.
    2. Selección de médico.
    3. Elección de fecha.
    4. Elección de horario disponible.
- **Gestión de Citas ("Mis Citas"):**
  - Consulta detallada de citas agendadas y su estado.
  - Opciones para **reprogramar** o **cancelar** citas con modal de confirmación.
- **Directorio de Médicos:**
  - Catálogo de especialistas e información sobre sus horarios.
- **Almacenamiento Local:**
  - Los datos se guardan directamente en el navegador del usuario (`localStorage`) para persistencia local durante las pruebas/demostraciones.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica de la aplicación.
- **CSS3 / Tailwind CSS:** Estilos modernos, diseño adaptativo (*responsive*) e interfaz limpia.
- **JavaScript (ES6+):** Lógica del lado del cliente, manipulación del DOM y persistencia de datos local (`localStorage`).
- **Google Fonts:** Tipografía optimizada para una excelente legibilidad.
